# Event Manager

A simple Python-based Event Manager application using SQLite.

## Features

- Add new events
- View all events
- Register students for events
- View student registrations
- Check whether an event ID exists
- Validate event capacity
- Store data using SQLite database

## Requirements

- Python 3.x
- SQLite3

No external Python packages are required.

## How to Run

Open the project folder in VS Code and run:

python main.py

## Menu Options

1. Add Event
2. View Events
3. Register Student
4. View Registrations
5. Exit

## Database

The application uses SQLite to store:

- Events
- Students
- Event registrations
